# Physics Learning Lab — ต้นแบบบทเรียนคลื่นกล

เว็บไซต์ต้นแบบสำหรับเผยแพร่ด้วย GitHub Pages สร้างด้วย HTML, CSS และ JavaScript ไฟล์เดียว

## วิธีทดลองในเครื่อง
1. ดาวน์โหลดและแตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `physics_learning_lab`
3. ดับเบิลคลิก `index.html` เพื่อเปิดใน Chrome หรือ Edge
4. ทดลองแถบเลื่อน ปุ่มบันทึกข้อมูล ดาวน์โหลด CSV และแบบทดสอบ

## วิธีเผยแพร่ด้วย GitHub Pages
1. เข้าสู่ระบบ https://github.com/
2. กด `+` แล้วเลือก `New repository`
3. ตั้งชื่อ เช่น `physics-learning-lab`
4. เลือก `Public` และสร้าง repository
5. กด `Add file` > `Upload files`
6. อัปโหลด `index.html` และ `README.md` จากโฟลเดอร์นี้ แล้วกด `Commit changes`
7. เข้า `Settings` > `Pages`
8. ในส่วน Build and deployment เลือก `Deploy from a branch`
9. เลือก branch `main` และ folder `/(root)` แล้วกด `Save`
10. รอสักครู่แล้วเปิด URL ที่แสดงในหน้า Pages โดยทั่วไปจะมีรูปแบบ `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`

## วิธีแก้ไขเนื้อหา
- เปิด `index.html` ด้วย VS Code หรือโปรแกรมแก้ไขข้อความ
- แก้ข้อความในส่วน HTML ได้โดยตรง
- สีและรูปแบบอยู่ในส่วน `<style>`
- การทำงานของแถบเลื่อน การบันทึกตาราง และแบบทดสอบอยู่ในส่วน `<script>`

## ข้อจำกัดของต้นแบบ
- คะแนนและข้อความที่ผู้เรียนพิมพ์ยังไม่ถูกส่งไปเก็บในฐานข้อมูลกลาง
- ไม่มีระบบบัญชีผู้ใช้/เข้าสู่ระบบ
- ตารางข้อมูลและคำตอบเป็นข้อมูลชั่วคราวในหน้าเว็บ ยกเว้น CSV ที่ผู้ใช้ดาวน์โหลด
- แบบจำลองคลื่นเป็นภาพประกอบเชิงแนวคิด ไม่ใช่การจำลองเชิงฟิสิกส์ที่ครอบคลุมทุกปัจจัย
- ก่อนใช้เป็นสื่อการสอนจริง ควรตรวจความถูกต้องของเนื้อหาและทดสอบบนโทรศัพท์/คอมพิวเตอร์ของโรงเรียน
